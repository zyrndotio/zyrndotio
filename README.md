> **Clean structure. Dirty edges.** I am a developer interested in interfaces with a point of view, thoughtful component systems, and tools that make the terminal feel alive.

## Focus

I work primarily with **TypeScript**, **React**, and **C#**, combining strong interaction design with practical engineering. I care about accessible foundations, clear APIs, deliberate theming, and software that feels considered from the first command to the final pixel.

| Area | What I am building |
| --- | --- |
| **UI systems** | Reusable, accessible React components with expressive visual language. |
| **Developer tools** | Practical command-line experiences and native object pipelines. |
| **Design systems** | Theme tokens, motion, typography, and interaction patterns that stay coherent at scale. |

## Selected work

| Project | Description | Stack |
| --- | --- | --- |
| [**Zyrn UI**](https://github.com/OdixCodez/Zyrn-UI) | A React component library shaped by woodblock, Gothic, and graffiti influences, with accessible primitives and a token-based theme system. | TypeScript, React |

| [**Kairo Themes**](https://github.com/OdixCodez/Kairo--Themes) | A refined collection of dark and light themes for Visual Studio Code. | VS Code |

## Working principles

```text
01  Build accessible primitives before ornamental surfaces.
02  Let the visual system carry intent, not noise.
03  Make developer experience a feature.
04  Ship the smallest coherent system, then refine it.
```

## Current direction

I am evolving **Zyrn UI** into a sharper, more expressive component system while continuing to explore the intersection of interface design, native tooling, and digital atmosphere.
